# Worker Improvement Log Template

Use this template for `.tmp/team-lead/worker-improvement-log.md`.

The log is for improving future dispatches, not for interrupting the current
worker. Do not include secrets, raw terminal dumps, credential paths, or long
worker logs. If the same pattern repeats, promote the lesson into `AGENTS.md`,
`CLAUDE.md`, or the relevant skill after the active task.

```markdown
# Worker Improvement Log

## <YYYY-MM-DD HH:MM> — <task_id or topic>

- Worker/session:
- Mode:
- Observation:
- Why this was not interrupted:
- Likely cause:
- Next dispatch adjustment:
- Parallelization opportunity:
- Prompt/context adjustment:
- Scope or validation adjustment:
- Durable rule candidate:
```
